# FriendCircle

一款仿微信朋友圈风格的 Typecho 主题：时间线式动态列表 + 九宫格图片 + 内联点赞评论，界面简洁，交互还原朋友圈手感。

## 特性

- **朋友圈式动态流**：封面大图、头像昵称、个性签名、时间线动态卡片（时间 / 位置 / 九宫格图片），长文自动折叠并跳转详情页
- **内联评论**：卡片内直接发表 / 回复评论，支持 OwO 表情面板、评论者头像、点击他人评论快速回复；评论成功后评论框自动收起；游客身份（昵称 / 邮箱 / 网址 / 头像）本地记忆 30 天（每次评论重新计时），与 Typecho 原生评论者记忆 cookie 互通、本地无记录时自动回退读取，后续评论免重复填写
- **点赞可取消**：再次点击取消点赞，状态本地记忆，防连点保护
- **详情页**：完整评论列表；Prism 代码高亮（本地内置无需 CDN，One Dark 式样、行号、一键复制、语言自动识别）
- **明暗双主题**：手动切换 + 跟随系统偏好，记忆在 localStorage
- **访问统计**：站点级访客统计条（今日 / 昨日 / 总访问，悬停查看近 7 / 30 天），IP + UA 指纹同日去重、爬虫不计入，MySQL / SQLite 双兼容，首次访问自动建表
- **背景音乐**：后台配置多条随机轮播，顶栏迷你播放器（播放 / 暂停、歌名、跳动音柱）
- **原生音/视频短代码**：内置 APlayer 与 ArtPlayer，无需安装播放器插件——编辑器一键插入或手写短代码：
  - 音乐：直链属性式 `[Music title="歌名" author="歌手" url="音频地址" pic="封面" lrc="歌词"/]`；Meting JSON `[Music {"name":"歌名","url":"音频地址","pic":"封面"}/]`；Meting API 链接 `[Music]https://api.injahow.cn/meting/?type=playlist&id=歌单ID[/Music]`（单曲 / 歌单自动识别，前端实时解析）；兼容 `[Meting]` 包裹格式
  - 视频：`[play]视频地址[/play]`，多个地址每行一个——一个播放器 + 分集切换按钮；竖屏视频按宽高比自适应（最大高度 300px）；兼容旧格式 `[Video url="视频地址" pic="封面"/]`
  - 全局媒体互斥（任一媒体播放时其它自动暂停）与 PJAX 切页自动重载内置
- **友情链接**：后台配置友链列表，顶栏入口弹窗展示（「联系人」风格）
- **搜索**：悬浮按钮弹出搜索条（回车提交，走 Typecho 原生搜索归档）
- **悬浮按钮组**：返回顶部、搜索、明暗切换、清除游客信息（存在本地评论身份记忆时出现，一键清空 localStorage 与 Typecho 原生评论者记忆 cookie——站点开启 Cookie httponly 时由服务端端点 `forget.php` 下发过期指令，HttpOnly cookie 同样清干净；清除后资料区即时恢复默认，已展开的评论表单同步清空）
- **AJAX 无限加载**：下拉自动加载下一页，失败点击重试；新卡片内播放器 / 代码块自动初始化
- **图片灯箱**：卡片与正文图片点击放大，原生实现无第三方依赖
- **响应式设计**：适配桌面端与移动端

## 环境要求

- Typecho 1.2+（基于 1.3 验证）
- PHP 7.3+

## 安装

1. 解压到 `usr/themes/` 目录，文件夹名保持 `FriendCircle`
2. 后台 → 控制台 → 外观 → 启用「FriendCircle」
3. 进入主题设置按需配置（封面、头像、背景音乐、友情链接等）

## 后台设置说明

按设置页自上而下的顺序排列：

| 设置项 | 说明 |
| --- | --- |
| 封面图片 / 视频 URL | 顶部封面大图，填 mp4/webm 视频地址时作为静音循环背景播放（不受媒体互斥影响），留空显示纯色渐变 |
| 封面类型 | 自动识别（按扩展名）/ 视频 / 图片；地址为无扩展名的跳转链接（如 302 到视频文件）时选「视频」 |
| 头像 URL 或邮箱 | 填图片地址，或填邮箱按「头像源」获取 |
| 头像源 | lty / cravatar / weavatar / loli / gravatar |
| 昵称 | 留空使用站点标题 |
| 个性签名 | 显示在头像下方，可留空 |
| 暗色模式 | 跟随系统并允许切换 / 仅亮色 / 仅暗色 |
| PJAX 无刷新跳转 | 站内点击不整页刷新，自动重载播放器与代码高亮，背景音乐跨页持续播放 |
| 插入位置按钮 | 默认关；开启后文章 / 页面编辑器工具栏出现「📍 插入位置」，点击把编辑者 IP 归属地填入「所在位置」字段；首次开启后进入任意后台页面自动下载 ip2region 数据库（IPv4 约 11MB + IPv6 约 37MB）到 `assets/ipdb/`，多源自动切换，下载失败弹窗提示原因 |
| PJAX 自定义重载函数 | 每行一条 JS 语句，PJAX 切页完成后依次执行，用于重载其它插件的组件；空行与 `//` 注释行跳过，留空不执行 |
| 动态内联评论数 | 首页每条动态展示的最新评论条数，默认 3 |
| 背景音乐 | 每行一条：`音乐地址\|歌名`（歌名可省略），保存后顶栏显示播放器 |
| 友情链接 | 每行一条：`名称\|地址\|头像地址`（头像可省略），保存后顶栏显示友链入口 |
| 访问统计 | 开关 + 位置（视口四角悬浮）+ 自动刷新间隔 + 统计时区 |

## 文章发布约定

- 发布动态使用「文章」，内容支持 Markdown；图片自动提取到卡片九宫格（最多 9 张）
- 自定义字段「所在位置」填地理位置（如 `江西·赣州`），显示在动态正文下方；也可开启「插入位置按钮」后点击编辑器工具栏「📍 插入位置」自动填入（ip2region 解析编辑者 IP 归属地，IPv4/IPv6 双库，国内精确到省市）；站点位于 CDN / 反代后归属地不准时，登录后浏览器打开 `usr/themes/FriendCircle/location.php?debug=1` 可诊断请求头与解析结果
- 正文中的代码块（``` 围栏）自动高亮，语言可标注也可自动识别
- 音/视频：编辑器工具栏「♪ 插入音乐」（Meting 歌曲 / 歌单链接或手动填参数）、「▶ 插入视频」（地址框每行一个，统一输出 `[play]` 格式，多个自动分集）一键生成短代码，或手写各格式短代码；首页卡片与详情页均会渲染播放器

## 目录结构

主题文件平铺在根目录，可在 Typecho 后台「控制台 → 外观 → 编辑」中直接编辑。

```
FriendCircle/
├── functions.php        # 主题设置、动态渲染、社交数据缓存、访问统计等服务端逻辑
├── comments.php         # 评论渲染与查询函数集（由 functions.php 加载）
├── media.php            # 原生音/视频短代码（APlayer / ArtPlayer 解析 + 编辑器按钮，由 functions.php 加载）
├── comments-ajax.php    # 评论 AJAX 接口（列表片段 / 提交）
├── like.php             # 点赞 AJAX 接口
├── forget.php           # 游客评论记忆清理端点（服务端下发过期 Set-Cookie，清除 HttpOnly 的原生评论者记忆 cookie）
├── location.php         # 位置 AJAX 接口（编辑器「插入位置」按钮，主题自带 ip2region 库解析归属地；?debug=1 诊断请求头）
├── ipdb.php             # ip2region 数据库管理（多源下载 + 归属地查询与格式化）
├── ipdb-download.php    # 数据库后台下载端点（后台页面自动触发，下载失败弹窗提示原因）
├── index.php            # 首页 / 归档页（搜索、分类、标签、作者）动态列表
├── post.php             # 详情页
├── page.php             # 独立页面
├── header.php           # 页头（暗色初始化、本地 Prism、顶栏）
├── footer.php           # 页尾（悬浮按钮组、友链 / 搜索弹窗、统计条、脚本）
├── style.css            # 全部样式源文件（含暗色模式），页面实际加载 style.min.css
├── style.min.css        # style.css 压缩产物（由 header.php 引用）
├── app.js               # 前端交互源文件（评论 / 点赞 / 加载 / 弹窗 / 统计等），页面实际加载 app.min.js
├── app.min.js           # app.js 压缩产物（由 footer.php 引用）
├── OwO.json             # OwO 表情码表
└── assets/
    ├── img/             # 主题默认图片（封面、默认头像）
    ├── ipdb/            # ip2region 数据库（ip2region.xdb / ip2region_v6.xdb，开启「插入位置按钮」后自动下载；附 .htaccess 禁止直连）
    └── lib/             # 本地库（aplayer.min.js/css、artplayer.min.js、prism/ 代码高亮及语言组件）
```

## 维护说明

- `app.js` 与 `style.css` 是源文件，供后期修改；页面实际引用压缩产物 `app.min.js` / `style.min.css`
- 修改源文件后需重新压缩（本机需 Node.js）：

```bash
npx terser app.js -c -m --comments "/FriendCircle|!/" -o app.min.js
npx esbuild style.css --minify --outfile=style.min.css
```
